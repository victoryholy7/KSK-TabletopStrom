KSK: STORM COMMAND

บัญชาการฝ่าวิกฤตพายุ

ซ้อมแผนบัญชาการเหตุการณ์พายุถล่ม โรงพยาบาลเขาสุกิม จังหวัดจันทบุรี ใช้การ์ดทรัพยากรจำกัด ตัดสินใจภายใต้เวลาจำกัด แล้วดูว่าจะต้องพัฒนาตรงไหน

เลือกเหตุการณ์สำหรับการซ้อม

เลือกเหตุการณ์ที่ต้องการซ้อมเองได้เลย (ติ๊กที่การ์ด) แนะนำ 5 เหตุการณ์ต่อ 45–60 นาที ยังไม่ได้เลือกเหตุการณ์ใดไว้ล่วงหน้า

เลือกแล้ว 0 เหตุการณ์
1. ฟังข่าวด่วน
ฟังตัวละครรายงานเหตุ แล้วทุกโต๊ะปรึกษากันว่าจะใช้ Item ใด
2. ลงการ์ด
แตะหมุดแดง แล้วเลือก Item ตามขั้น BCP (แต่ละเหตุมีขั้นตอน BCP 5–7 ขั้น ทีมรับผิดชอบแต่ละขั้นไม่เหมือนกัน) เลือกผิดเหตุจะลุกลาม จบแต่ละเหตุการณ์จะมีสรุปจุดแข็ง/จุดอ่อนและเฉลยทุกขั้นตอน
3. ให้คะแนน
จบรอบ ผู้ดำเนินการให้คะแนนความเร็ว ความถูกต้องตาม BCP และการประสานข้ามทีม

เหตุการณ์ทั้งหมดเป็นสถานการณ์สมมติเพื่อการซ้อมแผน ไม่ใช่เหตุการณ์จริง

ข่าวด่วน

    ให้เวลาโต๊ะปรึกษา แล้วกดเริ่มจับเวลา

    ผู้ดำเนินการประเมินแต่ละทีม (0–5)

    ค่าเริ่มต้นเป็น 0 คะแนน กรุณาเลื่อนคะแนนตามผลการปฏิบัติจริงของแต่ละทีม ไม่ได้กำหนดคะแนน 3 ไว้ล่วงหน้า
